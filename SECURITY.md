# Security and sensitive information

Do not commit passwords, API keys, access tokens, confidential information, student records, or data that the course is not permitted to redistribute.

If you accidentally commit a credential, deleting it in a later commit is not enough: the value remains in repository history. Revoke or rotate the credential immediately, then contact the instructor privately through the contact method listed in Canvas.

Do not open a public GitHub issue to report exposed student information or credentials.
