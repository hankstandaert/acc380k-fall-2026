# ACC 380K — Coding and Data Analysis in Accounting

Course materials for Fall 2026 at The University of Texas at Austin.

This repository is a student-facing home for selected notebooks, code, and project resources. Materials will be released as the semester progresses.

## Which platform should I use?

- **Canvas is the official course hub.** It controls announcements, policies, deadlines, required submissions, feedback, grades, and the current schedule.
- **GitHub holds selected versioned course materials.** Early in the semester, you will mostly use it to open course notebooks. Later, teams will use private repositories for Case 2.
- **Google Colab is our primary notebook environment.** Colab is where you will usually open, run, edit, and test the notebooks stored here.

If Canvas and another platform ever differ about a deadline or course requirement, Canvas controls.

## Getting started

No prior Git or GitHub experience is expected. We will introduce the workflow in stages and practice it in class.

When a notebook is released, its page in [`notebooks/`](notebooks/) will include an **Open in Colab** link and any setup instructions. Follow the corresponding Canvas instructions for saving your work and submitting the required final artifact.

## Repository map

- [`notebooks/`](notebooks/) — released student notebooks and opening instructions
- [`case2-starters/`](case2-starters/) — optional technical launchpads for Case 2
- [`data/`](data/) — documentation for data that may be safely distributed here

## Course work

- Do not submit graded work through this public repository unless Canvas explicitly tells you to do so.
- Case 2 team repositories will be private unless a team later chooses to publish its work after grading and everyone on the team agrees.

Questions about the course should go through the channels identified in Canvas.

## Status

This repository is being prepared for Fall 2026. Canvas remains the authoritative source for what is currently assigned or required.
