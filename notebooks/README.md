# Course notebooks

Released student notebooks will appear here as the semester progresses. Each release will include an **Open in Colab** link and any setup instructions needed for a fresh Colab session.

Until a notebook is listed here and assigned in Canvas, it is not required course work.

The usual workflow will be:

1. Open the released notebook from this repository in Colab.
2. Save your working copy where the corresponding Canvas instructions specify.
3. Read, predict, run, assess, and test as you work.
4. Restart the Colab session and run the notebook from top to bottom before final submission.
5. Submit the required artifact or link in Canvas.

GitHub stores notebook history; Colab runs the code. Opening a notebook from GitHub does not create an automatically synchronized shared editing session.
